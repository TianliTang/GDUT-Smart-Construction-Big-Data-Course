# 《大数据分析与云计算》课程项目任务说明

## 1. 任务目的

请选择一个智能建造业务方向，把它从一句业务困惑转化为一个可以复核的数据分析问题。你们要呈现的不是“用了什么算法”，而是：谁需要基于什么证据作出什么判断；数据能支持到哪里；结果为什么可信；建议为什么不能说得过头。

项目只考查大数据分析。云计算四讲是独立的理论学习内容，**不要求**购买、注册或操作云服务，不要求画云架构图，也不要求使用Docker、Hadoop、Spark或深度学习。

## 2. 选题方式

从本发布包的两套数据中任选一套，并从该数据包的四个场景委托中任选一个。选择前，请先阅读该数据包的项目概况和数据链，理解不同表格在同一业务流程中的位置；再阅读场景卡，确定你们要回应的具体委托。场景卡交代了业务角色、触发背景、当前困难与希望获得的支持，但不是标准题目，也不是答案提示。你们应在阅读数据说明、完成质量检查和初步EDA后，自主确定下列内容。

1. 决策使用者是谁，需作出什么判断；
2. 分析对象和记录粒度是什么；
3. 你们真正要回答的问题、输入与输出分别是什么；
4. 使用哪些表、哪些字段以及如何关联；
5. 选择哪一种或两种已学经典方法，为什么它比其他方法合适；
6. 如何设置基准、数据划分和评价指标；
7. 对结果能作出什么有条件的工程解释，哪些结论不能作出。

不要把“相关”“模型预测”或“统计显著”直接写成因果关系或必然的工程决策。

## 3. 每组最终交付

1. **汇报PPT**：10分钟陈述，建议按“问题与使用者—数据及质量—方法与评价—结果—工程解释与局限—分工”组织；
2. **可运行Notebook或Python代码**：在课程统一的Python 3.12＋venv＋Jupyter环境中，从头运行后可得到关键表格、图形和结果；
3. **数据说明**：说明使用的数据文件、关键字段、记录粒度、关联方式、质量处理和数据版本；
4. **小组分工与共同成果说明**；
5. **个人报告**：每名同学独立完成。可以引用本组共同的数据、代码输出和图表，但问题表述、图表解释、局限分析和最终结论须独立撰写。

第16讲进行6组汇报与问答，并同步提交个人报告。具体提交位置和文件命名以教师通知为准。

## 4. 最低分析证据链

无论场景属于描述、预测、风险筛查、异常识别还是分群，均应具备以下最小证据链：

`工程问题 → 数据字典与质量检查 → EDA/可视化 → 基准或比较对象 → 1—2种经典方法 → 评价 → 结果解释 → 局限与有条件建议`

### 必做的数据质量工作

- 核对每张表的主键/记录标识是否可用，说明表与表之间如何匹配；
- 检查缺失、重复、异常范围、类别编码和日期/时间字段；
- 说明处理规则及理由，并保留处理前后数量对照；
- 不得为了获得更“好看”的结果而无理由删除记录。

### 若采用预测或分类

- 必须设置一个合理的基准；
- 必须避免使用发生在目标之后的字段，或直接透露结果的字段；
- 时间相关数据应优先使用时间顺序切分，不能把未来记录随机混入训练集；
- 回归可报告MAE、RMSE、R²等；分类至少报告混淆矩阵及准确率、精确率、召回率、F1中的适当指标；
- 解释错误代价，不只比较一个最高分数。

### 若采用聚类、异常检测或统计比较

- 说明标准化、阈值、簇数或规则为何合理，并展示改变设置后的必要核验；
- 异常记录不等于错误记录或真实故障，应给出“需要人工复核”的清单或条件；
- 统计比较应同时说明效应大小、区间或样本不确定性，不能把p值当作工程重要性的唯一证据。

## 5. 评价关注点（不含未确认分值）

| 维度 | 重点 |
|---|---|
| 问题定义 | 问题、使用者、数据对象、输出和工程含义是否匹配。 |
| 数据理解与质量 | 记录粒度、字段选择、关联、质量检查和处理是否可复核。 |
| 方法与评价 | 方法是否与任务匹配；是否有基准、正确数据划分和恰当指标。 |
| 结果表达与解释 | 图表、表格和结论是否直接回答问题；是否区分模型结果、工程解释和决策。 |
| 局限与规范 | 是否避免泄漏、夸大因果、隐私/版权误用；是否说明数据和方法的局限。 |
| 小组协作与个人报告 | 分工是否清楚；个人报告是否独立且与共同成果边界明确。 |

## 6. 数据使用说明

- 所有数据均为教学仿真数据，不对应真实项目或设施，不能用于实际工程决策；
- CSV采用UTF-8 with BOM编码，可用Excel预览，也可用pandas读取；数据量较大，建议先只读取需要的列和日期范围；
- 数据中包含少量缺失、重复抽取、延迟上报或未完结记录。这些现象是数据质量分析的素材，不预先提供“正确清理答案”；
- 不得把数据包上传到其他公开网盘、其他公开代码仓库或用于课程外商业用途；课程报告和展示中的数据截图应说明“教学仿真数据”。

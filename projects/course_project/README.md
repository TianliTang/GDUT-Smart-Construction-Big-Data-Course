# 课程综合训练项目

本文件夹提供《智慧建造大数据分析》课程综合训练项目的学生使用材料。

## 文件说明

- `课程项目任务说明.md`：项目总体要求、提交内容和分析边界。
- `开放场景卡.md`：可选择的数据分析委托场景。
- `分析问题定义书模板.md`：小组前期确定分析问题时使用的模板。
- `data/数据包A_大跨度桥梁健康监测.zip`：大跨度桥梁健康监测教学数据包。
- `data/数据包B_桥隧设施养护运营.zip`：桥隧设施养护运营教学数据包。

## 使用方法

1. 下载本仓库后，先阅读 `课程项目任务说明.md`。
2. 从 A、B 两个数据包中选择一个。
3. 解压所选 ZIP 数据包，阅读其中的 README 和数据说明。
4. 再结合 `开放场景卡.md` 选择分析委托，填写 `分析问题定义书模板.md`。

## 注意

数据包为教学仿真数据，只用于本课程训练。分析结论应结合数据字段、记录粒度和适用边界解释，不应直接用于真实工程决策。

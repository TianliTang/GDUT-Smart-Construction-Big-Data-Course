# 第4讲运行环境

## 机房统一环境

- Windows 64位；
- Python 3.12.10；
- 虚拟环境：`D:\EngineeringBigData\venv`；
- JupyterLab；
- 课程统一依赖由机房管理员依据`授课计划/requirements-course.txt`课前安装并测试。

## 课堂启动

在Windows命令提示符中执行：

```bat
D:
cd \EngineeringBigData
venv\Scripts\activate
python --version
python M00_统计环境自检.py
jupyter lab
```

看到命令行前出现`(venv)`、Python版本为3.12.10，环境自检显示`CHECK_PASS`，并在浏览器中打开JupyterLab后，再进入本讲文件夹运行Notebook。不要在课堂上自行安装或升级软件包。

Notebook与`data`、`docs`、`figures`等目录使用相对路径。复制或提交材料时应保留完整文件夹结构。

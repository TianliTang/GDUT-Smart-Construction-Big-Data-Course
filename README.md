# 广东工业大学《智慧建造大数据分析》课程数据仓库

本仓库用于《智慧建造大数据分析》课程的课堂练习、数据分析训练和课程项目，提供学生可直接下载使用的数据、Notebook、Python 脚本和操作说明。

## 仓库内容

- `lessons/`：按讲次整理的课堂练习 Notebook、配套数据和说明。
- `datasets/`：课程共用教学数据、数据字典和字段说明。
- `projects/`：课程综合训练项目的学生任务说明和学生版数据。
- `docs/`：Python/Jupyter 环境说明、常见问题和下载使用说明。

当前仓库已包含课程综合训练项目的学生任务说明和 A/B 两套教学数据包；后续课堂练习材料会随课程材料审阅进度逐步补充。

## 使用方法

1. 点击绿色 **Code** 按钮，选择 **Download ZIP** 下载完整仓库。
2. 解压后进入相应讲次或项目文件夹。
3. 先阅读该文件夹中的 README 或说明文档。
4. 按说明安装 Python 环境和依赖包。
5. 保持 Notebook 与 `data/`、`docs/`、`figures/` 等配套文件夹的相对位置不变。

## 数据说明

仓库中的数据用于课堂教学和方法练习，部分为经过整理或合成的教学数据，不应直接用于实际工程决策。分析结果需要结合数据来源、适用条件和工程背景解释。

## 学习建议

- 先理解数据字段、记录粒度和工程背景，再运行代码。
- 修改筛选条件、分组字段或模型参数时，需要同步解释结果变化。
- 课程项目应围绕“问题定义—数据理解—分析过程—结果解释”组织材料。
